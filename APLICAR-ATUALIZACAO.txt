KURIO — ATUALIZAÇÃO DA ORGANIZAÇÃO DO CÓDIGO

O QUE MUDA
- A lógica de acesso à API foi agrupada em src/features/<domínio>/api.ts.
- A sessão foi movida para src/features/auth/session.ts.
- O carrinho de visitante foi movido para src/features/cart/storage.ts.
- A recuperação de checkout foi movida para src/features/checkout/resume.ts.
- O armazenamento local legado de pedidos foi separado em src/features/orders/storage.ts.
- As rotas continuam em src/routes, pois o TanStack Router gera a árvore de rotas a partir dessa pasta.
- ARCHITECTURE.md foi atualizado para explicar a nova organização.

COMO APLICAR NO WINDOWS
1. Feche o servidor de desenvolvimento (Ctrl+C no terminal).
2. Na pasta D:\Projetos\NFT, renomeie a pasta src atual para src-backup.
3. Extraia o conteúdo deste ZIP na raiz D:\Projetos\NFT. O ZIP contém a pasta src completa e ARCHITECTURE.md.
4. Confira se a nova pasta ficou em D:\Projetos\NFT\src (não em src\src).
5. No terminal, execute:
   npm run build
   npm run lint
   npm run test:e2e
6. Se tudo passar, você pode apagar src-backup. Guarde-a até terminar as verificações.

IMPORTANTE
- O ZIP contém a pasta src completa, não apenas os arquivos novos. Renomear a pasta antiga antes de extrair evita que arquivos removidos continuem no projeto.
- package.json, package-lock.json, assets públicos, configuração do Vite e testes não foram alterados.
- Esta é uma reorganização de módulos e imports; as rotas permanecem no lugar para preservar o roteamento baseado em arquivos.
