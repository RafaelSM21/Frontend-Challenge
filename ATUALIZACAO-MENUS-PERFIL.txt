Kurio — atualização das áreas do perfil

Extraia este ZIP na raiz do projeto e permita substituir os arquivos existentes.
O pacote preserva os caminhos relativos e reúne os arquivos novos/modificados em relação ao NFT(1).zip original.

Seções adicionadas ao menu Meu perfil:
- Atividade: histórico de pedidos locais confirmados.
- Lista de interesse: NFTs curtidos, com remoção de favoritos.
- Ofertas: cupom KURIO10 configurado no mock e link para o carrinho.
- Arquivos baixados: lista de NFTs comprados; não finge disponibilizar arquivos quando não existe arquivo associado.
- Suporte: formulário demonstrativo que guarda chamados apenas no navegador e informa essa limitação.

Validação: não foi possível executar build/typecheck porque a instalação local está incompleta (falta vite/client). Execute npm ci, npm run build, npm run lint e npm run test:e2e no seu ambiente antes de integrar.
